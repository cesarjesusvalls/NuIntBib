Data release for "Measurement of muon neutrino induced charged current interactions without charged
pions in the final state using a new T2K off-axis near detector WAGASCI-BabyMIND".

This folders contain the following files. Each file is explained as follows.

1. result_1d_momentum_dif.txt: contains one-dimensional differential cross section results as a function of momentum [CH,H2O]. The unit of the differential cross section and errors is 1e-39 [dsigma/dp]
2. result_1d_cosine_dif.txt: contains the values of the one-dimensional differential cross section results as a function of the cosine of muon momentum [CH,H2O]. The unit of the differential cross section and errors is 1e-39 [dsigma/dcos]
3. covariacne_matrix_momentum.txt: contains the values of the covariance matrix with the bins in the same order as in result_1d_diff_momentum.txt. The matrix is for the differential cross section as a function of muon momentum. The unit of each matrix element is 1e-78 [(dsigma/dp)^2].  
4. covariacne_matrix_cosine.txt: contains the values of the covariance matrix with the bins in the same order as in result_1d_diff_cosine.txt. The matrix is for the differential cross section as a function of the cosine of muon angle. The unit of each matrix element is 1e-81 [(dsigma/dcos)^2].
5. flux_release.root: contains the flux covariance matrix and nominal flux for muon neutrino (numu), anti-muon neutrino (numub), electron neutrino (nue), and anti-electron neutrino (nueb)
