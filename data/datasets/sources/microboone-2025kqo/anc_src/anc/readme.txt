MCC9_FluxHist_volTPCActive_numu.root file contains CV numu flux histogram.
The flux is calculated through volTPCActive volume.

To normalize to nu/POT/bin/cm2 apply the scale factor:
scale_factor=1/(4997.*5e8)/(256.35*233.);

There are 4997 flux files each with 5e8 protons each.
The volTPCActive cross section area is 256.35*233cm^2.
